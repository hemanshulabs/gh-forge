---
title: Updating
---

You can update `forge` either with the [GitHub CLI](https://cli.github.com) or by
downloading the binaries manually.

## Update Using `gh`

To update `forge` simply run:

```sh
gh extension upgrade hemanshulabs/forge
```

You should see an output similar to:

```sh
[forge]: upgraded from v4.16.2 to v4.17.0
✓ Successfully checked extension upgrades
```

Run `gh extension --help` for info on more commands.

## Update Manually

To manually update `forge`, you can download the binaries from the latest release on GitHub under:
https://github.com/hemanshulabs/forge/releases

Search for the binary that corresponds to your operating system and CPU
architecture.
