The `notificationSections` list configures your inbox tabs in the Notifications view.

```yaml [~/.config/forge/config.yml]
notificationSections:
  - title: Inbox
    filters: reason:mention,review_requested,author
    limit: 50

  - title: All
    filters: ""
    limit: 100
```

## Section Properties

### `title`

*(string, required)*

The tab name displayed in the carousel.

### `filters`

*(string, optional)*

Filter notifications by reason or repository. Common reasons include:
- `mention`: You were `@mentioned` directly.
- `review_requested`: Your review was requested on a PR.
- `author`: You authored the PR or issue.
- `assign`: You were assigned.
- `ci_activity`: CI workflow run updates.
- `subscribed`: You are watching the repository.

### `limit`

*(integer, optional, default: `50`)*

The maximum number of notifications to display per section.
