The `defaults` block controls how Forge initializes when launched.

```yaml [~/.config/forge/config.yml]
defaults:
  view: prs
  preview:
    open: true
    width: 60
    position: right
  refetchIntervalMinutes: 30
  confirmQuit: false
```

## Options

### `view`

Sets the active view when Forge launches.

| Value | Description |
| :--- | :--- |
| `prs` *(default)* | Pull Requests view |
| `issues` | Issues view |
| `notifications` | Notifications view |
| `repo` | Repository & Branches view (when inside a git repo) |

### `preview`

Controls the initial state and position of the sidebar preview pane.

- `open` *(boolean, default: `true`)*: Whether the preview sidebar is visible by default. You can toggle this during runtime with <kbd>p</kbd>.
- `width` *(integer, default: `60`)*: Percentage of the terminal width allocated to the sidebar preview when positioned on the right.
- `position` *(string, default: `"right"`)*: Location of the preview pane. Set to `"right"` for a vertical split, or `"bottom"` for a horizontal split. Toggle during runtime with <kbd>P</kbd>.

### `refetchIntervalMinutes`

*(integer, default: `30`)*

The interval in minutes after which Forge automatically refreshes all sections in the background. Set to `0` to disable automatic background refreshing.

### `confirmQuit`

*(boolean, default: `false`)*

When set to `true`, pressing <kbd>q</kbd> prompts you with `Quit forge? (y/n)` before closing the dashboard.
