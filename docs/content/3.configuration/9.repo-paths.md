The `repoPaths` section maps remote GitHub repositories to the local directories where they are cloned on your machine.

```yaml [~/.config/forge/config.yml]
repoPaths:
  hemanshulabs/gh-forge: ~/projects/gh-forge
  facebook/react: ~/work/react
  neovim/neovim: ~/src/neovim
```

## Why Map Repo Paths?

When Forge knows the local path of a repository:

1. **Local Branch Checkout**: Pressing <kbd>c</kbd> or <kbd>C</kbd> on any PR can automatically checkout the PR branch in your local clone.
2. **Terminal Diff Pagers**: Forge can execute full local diff viewers (like `delta`, `difftastic`, or `bat`) against local git commits.
3. **Custom Command Templates**: Custom shell commands can reference `{{.RepoPath}}` to execute commands (such as `npm test`, `git log`, or opening your editor) directly in the local repository:

```yaml [~/.config/forge/config.yml]
keybindings:
  prs:
    - key: e
      name: open in editor
      command: code {{.RepoPath}}
```

::tip
You can use the tilde (`~`) shorthand in paths; Forge automatically expands it to your home directory.
::
