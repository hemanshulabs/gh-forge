The `agentsSections` block configures tabs shown in the dedicated **Agents** view. This view is tailored for tracking and reviewing pull requests generated by automated AI assistants, bots, and CI processes.

```yaml [~/.config/forge/config.yml]
agentsSections:
  - title: Agent PRs
    filters: is:open is:pr author:app/dependabot,author:app/renovate archived:false
    limit: 50

  - title: Copilot & AI
    filters: is:open is:pr label:"ai","agent","automated" archived:false
    limit: 50
```

## Section Properties

### `title`

*(string, required)*

The text displayed on the tab in the carousel.

### `filters`

*(string, required)*

The GitHub search filter targeting automated agent work items. Common filters:
- `author:app/dependabot`
- `author:app/renovate`
- `label:"ai-generated"`
- `head:agent/*`

### `limit`

*(integer, optional, default: `50`)*

The maximum number of items to display.
