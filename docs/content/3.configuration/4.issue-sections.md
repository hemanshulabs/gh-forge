The `issuesSections` list configures each tab in the Issues view.

```yaml [~/.config/forge/config.yml]
issuesSections:
  - title: Assigned
    filters: is:open is:issue assignee:@me archived:false
    limit: 50

  - title: Created
    filters: is:open is:issue author:@me archived:false
    limit: 50

  - title: Mentioned
    filters: is:open is:issue mentions:@me archived:false
    limit: 50

  - title: Critical Bugs
    filters: is:open is:issue label:"bug","p0" archived:false
    limit: 30
```

## Section Properties

### `title`

*(string, required)*

The text displayed on the tab in the top carousel.

### `filters`

*(string, required)*

The GitHub search query used to fetch issues. Supports all standard issue qualifiers such as `assignee:@me`, `author:@me`, `label:"bug"`, `is:open`, and `repo:owner/repo`.

### `limit`

*(integer, optional, default: `50`)*

The maximum number of issues to fetch for this tab.
