Forge gives you complete control over how table columns are rendered in your PR and Issue views. You can set individual column widths, adjust growing behavior, or hide columns entirely.

## Configuring Columns

You can configure layout globally under `defaults.prs.layout` (or `defaults.issues.layout`), or per-section under each section's `layout` key:

```yaml [~/.config/forge/config.yml]
defaults:
  prs:
    layout:
      updatedAt:
        width: 8
      state:
        width: 3
      repo:
        width: 20
      title:
        grow: true
      author:
        width: 12
      reviewStatus:
        width: 3
      ci:
        width: 3
      lines:
        width: 14
      labels:
        hidden: true
```

## Available PR Columns

| Column | Default Width | Description |
| :--- | :--- | :--- |
| `updatedAt` | `7` | Relative time since last update (e.g., `2m`, `3h`, `5d`) |
| `state` | `3` | Status icon (Open, Draft, Merged, Closed) |
| `repo` | `15` | Repository name (or `owner/repo`) |
| `title` | `grow` | PR title; expands to fill remaining screen space |
| `author` | `10` | GitHub username of the author |
| `reviewStatus`| `3` | Review state icon (Approved, Changes Requested, Commented) |
| `ci` | `3` | CI check suites status (Passing, Failing, Pending) |
| `lines` | `16` | Lines added and deleted (`+12 -4`) |
| `numComments` | `3` | Total number of comments |
| `labels` | `hidden` | Color-coded label badges |

## Available Issue Columns

| Column | Default Width | Description |
| :--- | :--- | :--- |
| `updatedAt` | `7` | Relative time since last update |
| `state` | `3` | State icon (Open, Completed, Not Planned) |
| `repo` | `15` | Repository name |
| `title` | `grow` | Issue title |
| `author` | `10` | Author username |
| `assignees` | `12` | Assigned user handles |
| `numComments` | `3` | Number of comments |
| `labels` | `hidden` | Label badges |

## Column Options

- `width`: Number of characters allocated to the column. If content exceeds this width, it is truncated with `...`.
- `hidden`: Set to `true` to omit the column from the table.
- `grow`: Set to `true` to let the column dynamically expand to fill available horizontal width.
