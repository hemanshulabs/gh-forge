Forge is configured via a single declarative YAML file. It allows you to customize every aspect of your dashboard: which sections appear, their search filters, table layouts, themes, and custom keybindings.

## File Locations

Forge resolves its configuration using the following priority order:

1. **Explicit Flag (`--config <path>`)**:
   ```bash [Terminal]
   forge --config /path/to/my-config.yml
   ```
2. **Environment Variable (`$FORGE_CONFIG`)**:
   ```bash [Terminal]
   export FORGE_CONFIG="$HOME/dotfiles/forge.yml"
   ```
3. **Repository-Specific Config (`.forge.yml` / `.forge.yaml`)**:
   If you launch Forge inside a Git repository that contains a `.forge.yml` file at its root, Forge applies that project's configuration.
4. **User-Level Default Config**:
   - **macOS & Linux**: `~/.config/forge/config.yml` (or `$XDG_CONFIG_HOME/forge/config.yml`)
   - **Windows**: `%USERPROFILE%\.config\forge\config.yml`

::tip
If no configuration file exists when you first run Forge, it automatically generates a default file at your user path.
::

## Anatomy of `config.yml`

A complete configuration file includes the following top-level keys:

```yaml [~/.config/forge/config.yml]
# Default behaviors and initial state
defaults:
  view: prs
  preview:
    open: true
    position: right
  refetchIntervalMinutes: 30

# Pull Requests Sections (Tabs)
prSections:
  - title: Needs Review
    filters: is:open is:pr review-requested:@me
  - title: My PRs
    filters: is:open is:pr author:@me

# Issues Sections (Tabs)
issuesSections:
  - title: Assigned
    filters: is:open is:issue assignee:@me
  - title: Created
    filters: is:open is:issue author:@me

# Notifications Sections
notificationSections:
  - title: Notifications
    filters: reason:mention,review_requested

# Agents Sections
agentsSections:
  - title: Agents
    filters: is:open is:pr author:app/dependabot

# Visual Theme
theme:
  ui:
    theme: tokyonight

# Custom Keybindings
keybindings:
  universal: []
  prs: []
  issues: []
  notifications: []

# Remote-to-Local Repository Mapping
repoPaths:
  hemanshulabs/gh-forge: ~/projects/gh-forge
```
