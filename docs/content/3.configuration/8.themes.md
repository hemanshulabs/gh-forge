Forge provides built-in theme presets alongside comprehensive color palette customization.

## Built-In Themes

You can select a built-in theme in your configuration:

```yaml [~/.config/forge/config.yml]
theme:
  ui:
    theme: tokyonight # Options: tokyonight, catppuccin, gruvbox, nord, dracula, default
    sectionsShowCount: true
  table:
    showSeparators: true
    compact: false
```

### Available Presets
- `tokyonight`: Deep indigo backgrounds with vibrant cyan, purple, and yellow accents.
- `catppuccin`: Soothing pastel palette based on Catppuccin Mocha.
- `gruvbox`: Retro warm groove palette with soft earth tones.
- `nord`: Crisp, arctic, bluish clean palette.
- `dracula`: Classic dark theme with high-contrast vibrant accents.
- `default`: Clean terminal-native palette adapting to your shell's background.

## Custom Color Overrides

You can override individual colors or define your own complete palette using hex codes (`#RRGGBB` or `#RGB`) or ANSI indices (`0-255`):

```yaml [~/.config/forge/config.yml]
theme:
  colors:
    text:
      primary: "#c0caf5"
      secondary: "#a9b1d6"
      faint: "#565f89"
      warning: "#e0af68"
      success: "#9ece6a"
      error: "#f7768e"
    background:
      selected: "#283457"
    border:
      primary: "#3b4261"
      faint: "#1f2335"
```

## UI & Table Display Options

- `ui.sectionsShowCount` *(boolean, default: `true`)*: Show item counts next to section titles in the carousel (e.g. `Mine (12)`).
- `table.showSeparators` *(boolean, default: `true`)*: Render subtle divider lines between table rows.
- `table.compact` *(boolean, default: `false`)*: Reduce vertical line padding for ultra-high information density.
