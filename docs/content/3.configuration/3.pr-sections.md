The `prSections` list defines each tab shown in the Pull Requests view.

```yaml [~/.config/forge/config.yml]
prSections:
  - title: Needs Review
    filters: is:open is:pr review-requested:@me archived:false
    limit: 50

  - title: My PRs
    filters: is:open is:pr author:@me archived:false
    limit: 50

  - title: Subscribed
    filters: is:open is:pr -author:@me involves:@me archived:false
    limit: 50

  - title: All Open
    filters: is:open is:pr org:my-company archived:false
    limit: 100
```

## Section Properties

### `title`

*(string, required)*

The text displayed on the tab in the top carousel (e.g. `Needs Review`, `My PRs`).

### `filters`

*(string, required)*

The GitHub search query used to populate the section. Any standard GitHub pull request search qualifiers are supported.

::tip
Always append `archived:false` to your filters to exclude archived repositories and improve query performance.
::

### `limit`

*(integer, optional, default: `50`)*

The maximum number of items to fetch for this section.

### `layout`

*(object, optional)*

Override the default column layout specifically for this section. See [Table Layout & Columns](/configuration/layout) for full details.
