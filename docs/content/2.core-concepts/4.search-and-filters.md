Forge harnesses the full power of the GitHub Search API. Every section in your dashboard is powered by a GitHub search query.

## Live Search Mode

Press <kbd>/</kbd> while on any section to open the live search bar:

1. The cursor focuses on the search input box at the bottom of the table.
2. Type or modify the GitHub search query.
3. Press <kbd>Enter</kbd> to execute the query and reload the table.
4. Press <kbd>Esc</kbd> to cancel and keep the existing filter.

::note
Changes made in live search mode are transient for your current session. To make a query permanent, add it to your [configuration file](/configuration/pr-sections).
::

## Supported Search Qualifiers

You can use any standard GitHub search syntax in Forge queries:

### Pull Request Qualifiers

| Qualifier | Purpose | Example |
| :--- | :--- | :--- |
| `is:pr` | Limit results to pull requests | `is:pr is:open` |
| `is:open` / `is:closed` / `is:merged` | Filter by state | `is:pr is:merged` |
| `author:@me` | PRs you created | `is:pr author:@me` |
| `review-requested:@me` | PRs requesting your review | `is:pr review-requested:@me` |
| `reviewed-by:@me` | PRs you have reviewed | `is:pr reviewed-by:@me` |
| `draft:false` / `draft:true` | Filter drafts | `is:pr draft:false` |
| `status:success` / `status:failure` | CI check status | `is:pr status:failure` |

### Issue Qualifiers

| Qualifier | Purpose | Example |
| :--- | :--- | :--- |
| `is:issue` | Limit results to issues | `is:issue is:open` |
| `assignee:@me` | Issues assigned to you | `is:issue assignee:@me` |
| `author:@me` | Issues created by you | `is:issue author:@me` |
| `mentions:@me` | Issues mentioning your handle | `is:issue mentions:@me` |
| `label:name` | Filter by label name | `is:issue label:"bug"` |
| `-label:name` | Exclude a specific label | `is:issue -label:"wontfix"` |
| `no:assignee` | Unassigned issues | `is:issue is:open no:assignee` |
| `comments:>5` | Highly discussed issues | `is:issue comments:>10` |

### Repository & Scope Qualifiers

| Qualifier | Purpose | Example |
| :--- | :--- | :--- |
| `repo:owner/repo` | Target a single repository | `repo:hemanshulabs/gh-forge` |
| `org:name` | Target an entire GitHub organization | `org:my-company is:open` |
| `user:name` | Target a user's repositories | `user:hemanshulabs` |
| `archived:false` | Exclude archived repositories | `archived:false` |

## Example Combined Queries

### Review Queue
```text
is:open is:pr review-requested:@me archived:false
```

### Needs My Attention (Assigned Bugs)
```text
is:open is:issue assignee:@me label:bug,p0,urgent
```

### AI Coding Agent PRs
```text
is:open is:pr author:app/dependabot author:app/renovate
```
