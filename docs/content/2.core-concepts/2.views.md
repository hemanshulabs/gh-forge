Forge provides focused views for pull requests, issues, notifications, and local repository work.

## Switching Views

You can switch between views in two ways:
- **Keyboard**: Press <kbd>s</kbd> to cycle between views.
- **Mouse**: Click directly on the view names in the footer bar: `[ Notifications | PRs | Issues ]`.

---

## 1. Pull Requests View (`prs`)

The Pull Requests view is the command center for code review and PR management.

### Features
- **Review Requests**: View PRs where your review is requested or pending.
- **My PRs**: Track PRs authored by you, including CI check statuses (passing, failing, pending).
- **Direct Review Actions**:
  - Press <kbd>v</kbd> or review keys to submit approvals or comments.
  - Press <kbd>d</kbd> to view full diffs via your configured terminal pager (e.g., `delta`, `bat`, or `less`).
  - Press <kbd>c</kbd> or <kbd>C</kbd> to checkout the PR branch directly to your local working tree.
  - Press <kbd>m</kbd> to merge PRs.
  - Press <kbd>l</kbd> to manage labels.
  - Press <kbd>a</kbd> to assign or unassign reviewers.

---

## 2. Issues View (`issues`)

The Issues view streamlines issue triage and tracking across all repositories you contribute to.

### Features
- **Triage Sections**: Categorize issues by Assigned to Me, Created by Me, Mentioned, or custom repository labels.
- **Conversation Thread**: Read complete issue descriptions, Markdown formatting, and user replies directly in the preview sidebar.
- **Issue Actions**:
  - Press <kbd>x</kbd> to close an issue (with confirmation prompt).
  - Press <kbd>X</kbd> to reopen a closed issue.
  - Press <kbd>c</kbd> to add a comment directly from the terminal.
  - Press <kbd>l</kbd> to toggle labels.
  - Press <kbd>a</kbd> to modify assignees.
  - Press <kbd>C</kbd> to create and checkout a new local branch linked to the issue.

---

## 3. Notifications View (`notifications`)

The Notifications view replaces the noisy GitHub web notification inbox with an ultra-fast keyboard triage workflow.

### Features
- **Grouped & Filterable**: Group notifications by repository or reason (mention, review requested, author, subscribed).
- **Embedded PR & Issue Inspection**: Press <kbd>Enter</kbd> on any notification to fetch and preview the full underlying PR or Issue in the sidebar without opening a browser.
- **Triage Actions**:
  - Press <kbd>d</kbd> to mark the selected notification as done / read.
  - Press <kbd>D</kbd> to mark all notifications in the current section as done (with confirmation prompt).
  - Press <kbd>o</kbd> to open the thread directly in your default web browser.
  - Press <kbd>Esc</kbd> to return back to the notification overview from a preview.

---

## 4. Repository & Branches View (`repo`)

When you launch Forge inside an active Git repository, the Repository view provides local git inspection alongside remote GitHub data.

### Features
- **Branch Browser**: View local branches and remote tracking branches with upstream sync status.
- **Branch Actions**:
  - Checkout branches with <kbd>Enter</kbd>.
  - Create new branches with <kbd>n</kbd>.
  - Delete local branches safely with <kbd>x</kbd> (Forge prompts for confirmation before deleting).
- **Recent Commits**: Inspect commit hashes, author timestamps, and commit messages.
