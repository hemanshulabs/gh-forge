Forge organizes your GitHub data into an intuitive, responsive terminal layout designed for high-density information display without visual clutter.

## Anatomy of the Interface

Forge's interface is divided into four main regions:

```text
┌────────────────────────────────────────────────────────────────────────┐
│  Tabs Carousel (Mine, Review, All)   [+]      FORGE v0.1.0   Update   │ <- Header
├──────────────────────────────────────┬─────────────────────────────────┤
│                                      │                                 │
│  Main Items Table                    │  Sidebar Preview Pane           │
│  - PR / Issue / Notification rows    │  - Title, author, branch, stats │
│  - Status icons, checks, reviewers   │  - Rendered Markdown body       │
│  - Highlighted selection             │  - Activity & Comments thread   │
│                                      │  - CI/CD Checks & Reviews       │
│                                      │                                 │
├──────────────────────────────────────┴─────────────────────────────────┤
│  1/24 (Page 1)  [PRs | Issues | Notifications]            ✔ Ready      │ <- Footer
└────────────────────────────────────────────────────────────────────────┘
```

### 1. Header & Tabs Carousel

Located at the top of the screen:
- **Tabs Carousel**: Displays each configured section (tab) in the active view. When there are more tabs than screen width, overflow arrows (`←`, `→`) appear.
- **Section Creator Button (`[+]` / `a`)**: Quick access to add new temporary sections.
- **Logo & Version**: Shows `FORGE` and current version.
- **Update Indicator**: When a newer release is published on GitHub, a badge appears: ` New version available: vX.Y.Z [U to update]`.

### 2. Main Items Table

The primary list for the active section:
- Formatted with customizable columns (title, author, repository, updated time, CI checks, review status, comments count).
- Highlights the currently focused row.
- Supports paging and infinite scroll as you move down the list.

### 3. Sidebar Preview Pane

A contextual preview that automatically syncs with the currently selected item:
- **Overview Tab**: Displays author, status badge, created/updated timestamps, base and head branches, labels, assignees, milestones, and full rendered markdown body.
- **Activity Tab**: Complete comment timeline with conversation threads, commit pushes, review submissions, and automated check runs.
- **Responsive Sizing**: Can be toggled open/closed with <kbd>p</kbd>, or shifted between a side-by-side right position and a bottom split position with <kbd>P</kbd>.

### 4. Interactive Footer

Located at the bottom of the screen:
- **Left Status**: Pagination indicator (e.g. `1/35`), pager info, or confirmation prompts for critical actions (such as closing an issue or deleting a branch).
- **View Switcher Bar**: Clickable buttons for `Notifications`, `PRs`, and `Issues`.
- **Right Status**: Background task spinner and completion notifications (e.g. `Checking for updates...`, `Opened in browser`, `Copied to clipboard`).
- **Help Indicator**: Press <kbd>?</kbd> to view the full keyboard help card.
