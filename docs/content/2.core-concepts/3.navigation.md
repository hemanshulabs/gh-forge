Forge is engineered for speed. It combines full keyboard ergonomics with natural mouse controls so you can navigate comfortably using whichever input style you prefer.

## Keyboard Navigation

### Moving Between Rows

| Key | Alternative | Action |
| :--- | :--- | :--- |
| <kbd>j</kbd> | <kbd>↓</kbd> | Move down to next item |
| <kbd>k</kbd> | <kbd>↑</kbd> | Move up to previous item |
| <kbd>g</kbd> | <kbd>Home</kbd> | Jump to first item in table |
| <kbd>G</kbd> | <kbd>End</kbd> | Jump to last item in table |

### Switching Tabs & Sections

| Key | Alternative | Action |
| :--- | :--- | :--- |
| <kbd>l</kbd> | <kbd>→</kbd> or <kbd>]</kbd> | Switch to next section tab |
| <kbd>h</kbd> | <kbd>←</kbd> or <kbd>[</kbd> | Switch to previous section tab |

### Scrolling the Preview Sidebar

| Key | Alternative | Action |
| :--- | :--- | :--- |
| <kbd>J</kbd> | <kbd>PgDown</kbd> | Scroll preview sidebar down one page |
| <kbd>K</kbd> | <kbd>PgUp</kbd> | Scroll preview sidebar up one page |
| <kbd>Tab</kbd> | | Switch between Overview and Activity tabs in sidebar |

### Preview Pane Layout

| Key | Action |
| :--- | :--- |
| <kbd>p</kbd> | Toggle preview sidebar open or closed |
| <kbd>P</kbd> | Toggle preview position between **Right** and **Bottom** |

## Mouse Controls

Forge includes integrated [Bubble Zone](https://github.com/lrstanley/bubblezone) mouse support:

### Natural Mouse Wheel Scrolling
- **Over the Main Table**: Scrolling your mouse wheel up or down moves the selected row. When you reach the bottom of a page, Forge automatically fetches the next page of items.
- **Over the Preview Sidebar**: Scrolling your mouse wheel up or down smoothly scrolls the preview text and comment activity without shifting focus away from the current item.

### Clickable Interactive Zones
- **Header Tabs**: Click on any section tab in the carousel to switch to it immediately.
- **Section Creator**: Click the `[+]` button next to the tabs to create a new live section.
- **Footer View Switcher**: Click on `Notifications`, `PRs`, or `Issues` in the bottom bar to switch views.
- **Update Indicator**: When a new version is available, click the ` New version available` badge in the header to trigger an auto-update.
- **Sponsor Button**: Click the sponsor link in the footer or header to visit GitHub Sponsors.

## Global Shortcuts

| Key | Action | Description |
| :--- | :--- | :--- |
| <kbd>?</kbd> | Help Menu | Toggle the interactive help card showing all bindings |
| <kbd>/</kbd> | Search | Focus the search input bar to edit the section's query |
| <kbd>r</kbd> | Refresh Section | Re-fetch data for the currently active section |
| <kbd>R</kbd> | Refresh All | Re-fetch data across all sections in the active view |
| <kbd>s</kbd> | Switch View | Cycle between PRs, Issues, and Notifications |
| <kbd>y</kbd> | Copy Number | Copy the PR or Issue number to system clipboard |
| <kbd>Y</kbd> | Copy URL | Copy the GitHub web URL to system clipboard |
| <kbd>o</kbd> | Open in Browser | Open the selected item in your default web browser |
| <kbd>U</kbd> | Update CLI | Check for updates and upgrade Forge to latest version |
| <kbd>Ctrl+L</kbd> | Redraw Screen | Redraw the terminal screen to clear artifacts |
| <kbd>q</kbd> | Quit | Exit Forge and return to your shell |
