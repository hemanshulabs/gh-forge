Forge provides multiple ways to keep your installation current, including instant in-app updating.

## Method 1: In-App One-Key Update (Recommended)

Forge features automated release detection and one-key in-app upgrading.

### How it Works

1. **Automatic Release Check**: At startup and on demand, Forge queries the GitHub GraphQL API for the latest release published on `hemanshulabs/gh-forge`.
2. **Update Indicator**: When a newer version is released, Forge highlights an update banner in the top-right header:
   ```text
    New version available: v0.2.0 [U to update]
   ```
3. **Trigger Update**:
   - Press <kbd>U</kbd> on your keyboard, OR
   - Click the update banner directly with your mouse.
4. **Auto-Upgrade Process**: Forge executes the upgrade in the background. The task status in the bottom right indicates:
   ```text
   New version v0.2.0 available! Updating forge...
   ```
5. **Completion**: Once finished, Forge notifies you:
   ```text
   ✔ Updated to v0.2.0! Please restart forge.
   ```

::tip
You can press <kbd>U</kbd> at any time to check for updates. If you are already running the latest release, Forge informs you with:
`✔ forge is up to date (v0.1.0)`.
::

## Method 2: GitHub CLI

If you installed Forge as a GitHub CLI extension, you can upgrade it from your terminal:

```bash [Terminal]
gh extension upgrade forge
```

Or target the full repository name:

```bash [Terminal]
gh extension upgrade hemanshulabs/gh-forge
```

Expected output:

```text [Terminal]
[forge]: upgraded from v0.1.0 to v0.2.0
✓ Successfully checked extension upgrades
```

## Method 3: Manual Binary Download

If you run Forge as a standalone compiled binary:

::steps
### Visit GitHub Releases

Go to the [Releases page](https://github.com/hemanshulabs/gh-forge/releases).

### Download the binary

Select the archive matching your operating system and CPU architecture (e.g. `forge_Darwin_arm64.tar.gz`, `forge_Linux_x86_64.tar.gz`, `forge_Windows_x86_64.zip`).

### Extract and replace

Extract the binary and replace your existing `forge` executable in `$PATH`.
::
