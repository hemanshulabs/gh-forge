Welcome to **Forge**, an open-source, highly responsive terminal dashboard for GitHub built with Go and the [Charm](https://charm.sh) TUI ecosystem ([Bubble Tea](https://github.com/charmbracelet/bubbletea), [Lip Gloss](https://github.com/charmbracelet/lipgloss), and [Bubbles](https://github.com/charmbracelet/bubbles)).

## What is Forge?

Switching back and forth between your code editor, terminal, and browser tabs to check PR statuses, read review comments, and triage issues breaks your flow state.

**Forge** (`gh forge`) brings your entire GitHub workspace into your terminal:

- **Review Pull Requests**: Read diffs, approve, merge, and leave comments without opening a browser.
- **Triage Issues**: Filter issues across multiple repositories, inspect labels, assign members, and close or reopen tickets.
- **Clear Notifications**: Manage notifications with keyboard shortcuts; preview related PRs and Issues instantly.
- **Manage AI Agents**: Keep automated coding agents and bots isolated in a dedicated section.
- **Local Branch Actions**: Checkout PR branches directly into your local working directory with automatic branch detection.

## Design Philosophy

1. **Keep Developers in the Flow**: Context switching kills momentum. By running Forge inside your existing terminal multiplexer (tmux, Zellij) or terminal tab, GitHub work items remain at your fingertips.
2. **First-Class Keyboard Ergonomics**: Every action has a single-key shortcut. Rebind any key to fit your personal muscle memory.
3. **No Lock-in**: Forge is a pure client for GitHub. It works seamlessly as a GitHub CLI extension (`gh forge`) or standalone executable using your existing `gh auth` credentials.
