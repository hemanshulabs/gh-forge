Forge can be installed as an official [GitHub CLI (`gh`)](https://cli.github.com) extension or built manually from source.

## Prerequisites

Before installing Forge, make sure you have:

1. **GitHub CLI (`gh`)** installed and authenticated:
   ```bash [Terminal]
   gh auth login
   ```
2. **A Nerd Font** configured in your terminal (recommended for rich icons like Git branches, checkmarks, spinners, and status badges).

---

## Recommended: GitHub CLI Extension

::steps
### Install the extension

Run the following command in your terminal:

```bash [Terminal]
gh extension install hemanshulabs/gh-forge
```

### Install a Nerd Font (Recommended)

To ensure icons (PR status, Git branches, CI checks) render crisply, install any [Nerd Font](https://www.nerdfonts.com):

```bash [macOS]
brew install --cask font-fira-code-nerd-font
```

```bash [Linux / Windows]
# Download your preferred font from nerdfonts.com (e.g., FiraCode, JetBrains Mono, Meslo)
# and set it as your terminal emulator's primary font.
```

### Verify installation

Run Forge to launch the dashboard:

```bash [Terminal]
gh forge
```

Or check the version:

```bash [Terminal]
gh forge --version
```
::

::tip
You can create an alias in your shell configuration (`~/.zshrc`, `~/.bashrc`, or PowerShell profile) for faster launching:
```bash
alias forge="gh forge"
```
::

## Manual Installation from Source

If you prefer building from source or contributing to Forge development:

::steps
### Clone the repository

```bash [Terminal]
git clone https://github.com/hemanshulabs/gh-forge.git
cd gh-forge
```

### Install locally as an extension

```bash [Terminal]
gh extension install .
```

### Or compile the standalone binary

```bash [Terminal]
go build -o forge .
```

Move the compiled binary to a directory in your `$PATH` (such as `/usr/local/bin` or `C:\Windows\System32`).
::

::note
When installed as a GitHub CLI extension, you run it via `gh forge`. When installed as a standalone binary in your `$PATH`, you can run it directly as `forge`.
::
