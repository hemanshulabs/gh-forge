Once installed, launching Forge is as simple as running `forge` or `gh forge` in your terminal.

```bash [Terminal]
forge
```

When Forge opens, press <kbd>?</kbd> at any time to toggle the contextual help overlay listing available keys.

---

## Command Line Flags

Run `forge --help` to inspect all supported options:

```text [Terminal]
Usage:
  forge [flags]

Flags:
  -c, --config string   use this configuration file (default lookup: .forge.yml, $FORGE_CONFIG, or $XDG_CONFIG_HOME/forge/config.yml)
      --debug           passing this flag will allow writing debug output to debug.log
  -h, --help            help for forge
  -v, --version         version for forge
```

### `--config` / `-c`

Specify a custom path to a YAML configuration file.

```bash [Terminal]
forge --config ~/.config/my-forge-config.yml
```

| Flag | Type | Default |
| :--- | :--- | :--- |
| `-c`, `--config` | `string` | Discovered automatically via configuration lookup hierarchy |

### `--debug`

Enables debug logging. When enabled, Forge outputs verbose logs to a `debug.log` file in the current working directory.

```bash [Terminal]
forge --debug
```

| Flag | Type | Default |
| :--- | :--- | :--- |
| `--debug` | `boolean` | `false` |

::tip
If you encounter unexpected behavior or want to inspect GraphQL API queries and network timings, launch with `--debug` and monitor logs in another terminal window with `tail -f debug.log`.
::

### `--help` / `-h`

Prints the CLI usage guide and exits immediately.

```bash [Terminal]
forge --help
```

### `--version` / `-v`

Outputs the compiled version string of Forge and exits immediately.

```bash [Terminal]
forge --version
```

## Configuration Discovery Order

If you do not pass `--config`, Forge locates its configuration using the following priority order:

1. **`$FORGE_CONFIG` environment variable**: If set to a valid file path, Forge uses it.
2. **Repository Root `.forge.yml` or `.forge.yaml`**: If you run Forge from inside a git repository containing `.forge.yml`, Forge uses it for repo-specific views and settings.
3. **`$XDG_CONFIG_HOME` User Config**: If set, `$XDG_CONFIG_HOME/forge/config.yml`.
4. **Default System Path**:
   - **Linux & macOS**: `~/.config/forge/config.yml`
   - **Windows**: `%USERPROFILE%\.config\forge\config.yml`

If no configuration file exists at startup, Forge automatically generates a sensible default configuration file so you can get started right away.
