We welcome contributions of all kinds: bug fixes, performance improvements, new features, and documentation enhancements!

## Development Setup

### Prerequisites

- **Go 1.23+** installed
- **GitHub CLI (`gh`)** authenticated (`gh auth login`)
- **Git**

::steps
### Fork and clone the repository

```bash [Terminal]
git clone https://github.com/hemanshulabs/gh-forge.git
cd gh-forge
```

### Run Forge in development mode

You can build and run Forge immediately using Go:

```bash [Terminal]
go run .
```

To run with verbose debug logs written to `debug.log`:

```bash [Terminal]
go run . --debug
```

### Run tests

Execute the automated test suites:

```bash [Terminal]
# Run all tests
go test ./...

# Run unit tests for TUI components
go test ./internal/tui/...

# Run utils and keys tests
go test ./internal/utils/... ./internal/tui/keys/...
```
::

## Codebase Architecture

Forge is structured as a modular Go codebase:

```text
forge/
├── cmd/               # CLI commands and Cobra root command (`cmd/root.go`)
├── internal/
│   ├── config/        # YAML configuration parser, validation, and defaults
│   ├── data/          # GitHub GraphQL API client, caching, and release checks
│   ├── git/           # Local Git integration, branch inspection, origin parsing
│   ├── shell/         # OS shell execution utilities
│   ├── utils/         # Version comparison, string formatting, terminal helpers
│   └── tui/           # Charm Bubble Tea model, view rendering, components
│       ├── components/
│       │   ├── carousel/      # Top tabs carousel with overflow indicators
│       │   ├── footer/        # Interactive bottom bar, view switchers, task state
│       │   ├── prview/        # Pull request overview, activity, and diff pager
│       │   ├── issueview/     # Issue overview, comments, and action inputs
│       │   ├── notificationview/ # Notification embedded preview
│       │   ├── tabs/          # Header logo, version, and update indicator
│       │   └── section/       # Generic table section interface
│       ├── context/   # Shared application state and Lip Gloss styles
│       └── keys/      # Keymap definitions, bindings, and dynamic rebinding
└── docs/              # Nuxt Content / Docus documentation website
```

## Submitting Pull Requests

1. Create a feature branch:
   ```bash [Terminal]
   git checkout -b feat/my-new-feature
   ```
2. Write clean, idiomatic Go code adhering to existing project conventions.
3. Add unit tests for your changes.
4. Ensure all tests pass (`go test ./...`).
5. Open a Pull Request on [hemanshulabs/gh-forge](https://github.com/hemanshulabs/gh-forge).
