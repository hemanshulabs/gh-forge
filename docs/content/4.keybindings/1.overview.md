Keyboard navigation is at the heart of the Forge experience. Every interaction—from moving between items to running custom shell scripts—can be executed without reaching for the mouse.

## The Interactive Help Menu

Press <kbd>?</kbd> at any time to open the built-in help card at the bottom of the screen.

- The help card dynamically reflects the active view (`prs`, `issues`, `notifications`, `agents`, or `repo`).
- Custom keybindings you define in your configuration are automatically displayed alongside built-in commands with their configured `name`.
- Press <kbd>?</kbd> again to close the menu.

---

## Rebinding Built-In Keys

Every built-in command can be rebound in your `config.yml` using the `builtin` property:

```yaml [~/.config/forge/config.yml]
keybindings:
  universal:
    # Rebind search from '/' to 'Ctrl+F'
    - key: ctrl+f
      builtin: search
    # Rebind update CLI
    - key: U
      builtin: updateCLI
```

## Key Value Syntax

Key values follow standard terminal key names:
- Single characters: `a`, `b`, `c`, `A`, `B`, `C`
- Modifiers: `ctrl+a`, `alt+b`
- Function keys: `f1` through `f12`
- Special keys: `enter`, `esc`, `tab`, `space`, `backspace`, `delete`, `up`, `down`, `left`, `right`, `home`, `end`, `pgup`, `pgdown`
