When focused on the **Issues** view, the following actions can be performed on the highlighted issue:

## Keybindings Table

| Key | Builtin | Description |
| :--- | :--- | :--- |
| <kbd>c</kbd> | `comment` | Open inline input box to post a comment on the issue |
| <kbd>x</kbd> | `close` | Close the issue (prompts confirmation in footer) |
| <kbd>X</kbd> | `reopen` | Reopen a closed issue |
| <kbd>C</kbd> | `checkout` | Create and checkout a new local branch linked to the issue |
| <kbd>a</kbd> | `assign` | Assign a teammate or user to the issue |
| <kbd>A</kbd> | `unassign` | Unassign an assignee from the issue |
| <kbd>L</kbd> | `label` | Open fuzzy label selector to add or remove labels |
| <kbd>y</kbd> | `copyNumber` | Copy the issue number to system clipboard |
| <kbd>Y</kbd> | `copyUrl` | Copy the GitHub web URL to system clipboard |
| <kbd>o</kbd> | `openGithub` | Open the issue in your default web browser |

---

## Action Highlights

### Creating a Branch for an Issue (`C`)
Pressing <kbd>C</kbd> prompts you for a new branch name (pre-populated with the issue number and slugified title). Forge creates the local Git branch and checks it out so you can begin working on the fix immediately.

### Safe Confirmation Prompts
Destructive state changes like closing an issue (<kbd>x</kbd>) prompt a confirmation in the footer (`Confirm close issue #123? (y/n)`), preventing accidental clicks.
