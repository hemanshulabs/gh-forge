Forge allows you to define arbitrary shell commands and bind them to any key combination. When you press the bound key, Forge pauses the TUI, shells out to execute your command, and refreshes the view upon completion.

## Configuration Syntax

Add keybindings under `keybindings.universal`, `keybindings.prs`, `keybindings.issues`, or `keybindings.notifications`:

```yaml [~/.config/forge/config.yml]
keybindings:
  prs:
    # Open LazyGit in the local cloned repository
    - key: g
      name: lazygit
      command: cd {{.RepoPath}} && lazygit

    # Auto-merge PR via gh CLI
    - key: M
      name: auto-merge
      command: gh pr merge --auto --squash --repo {{.RepoName}} {{.PrNumber}}

    # Open PR in VS Code
    - key: e
      name: open in code
      command: code {{.RepoPath}}

  issues:
    # Open issue in GitHub mobile / browser
    - key: B
      name: gh browse
      command: gh issue view --repo {{.RepoName}} --web {{.IssueNumber}}
```

## Available Template Variables

When Forge executes your command, it replaces Go template variables with data from the currently selected row:

### Universal & PR Template Variables

| Variable | Example Value | Description |
| :--- | :--- | :--- |
| `{{.RepoName}}` | `hemanshulabs/gh-forge` | Repository `owner/name` |
| `{{.RepoPath}}` | `/home/user/code/forge` | Local filesystem path (from `repoPaths`) |
| `{{.PrNumber}}` | `42` | Pull request number |
| `{{.HeadRefName}}` | `feat/awesome` | Source head branch name |
| `{{.BaseRefName}}` | `main` | Target base branch name |
| `{{.Url}}` | `https://github.com/...` | Web URL of the item |

### Issue Template Variables

| Variable | Example Value | Description |
| :--- | :--- | :--- |
| `{{.RepoName}}` | `hemanshulabs/gh-forge` | Repository `owner/name` |
| `{{.IssueNumber}}`| `101` | Issue number |
| `{{.Url}}` | `https://github.com/...` | Web URL of the issue |

### Notification Template Variables

| Variable | Example Value | Description |
| :--- | :--- | :--- |
| `{{.RepoName}}` | `hemanshulabs/gh-forge` | Repository name |
| `{{.Number}}` | `42` | Number of the linked PR or Issue |
| `{{.NotificationId}}` | `123456789` | GitHub notification thread ID |
