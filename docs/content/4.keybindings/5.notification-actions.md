When focused on the **Notifications** view, you can rapidly triage incoming alerts from GitHub:

## Keybindings Table

| Key | Builtin | Description |
| :--- | :--- | :--- |
| <kbd>Enter</kbd> | `view` | Load and preview linked PR or Issue directly in sidebar |
| <kbd>Esc</kbd> | `backToNotification` | Return from detailed preview back to notification prompt |
| <kbd>D</kbd> | `markAsDone` | Mark the selected notification thread as done / completed |
| <kbd>Alt+D</kbd> | `markAllAsDone` | Mark all notifications in the active section as done |
| <kbd>m</kbd> | `markAsRead` | Mark notification as read |
| <kbd>M</kbd> | `markAllAsRead` | Mark all notifications in active section as read |
| <kbd>u</kbd> | `unsubscribe` | Unsubscribe from the notification thread |
| <kbd>b</kbd> | `toggleBookmark` | Bookmark / save notification |
| <kbd>o</kbd> | `open` | Open notification thread in web browser |
| <kbd>r</kbd> | `refresh` | Refresh notification inbox |

---

## The Notification Triage Workflow

1. Move up and down with <kbd>j</kbd> and <kbd>k</kbd> to inspect notification subjects.
2. Press <kbd>Enter</kbd> on any notification to fetch the complete PR or Issue into the sidebar preview.
3. If it is a PR notification, you can even approve (<kbd>v</kbd>), diff (<kbd>d</kbd>), or comment (<kbd>c</kbd>) directly without leaving the notification view!
4. Press <kbd>D</kbd> to mark it done. It is immediately removed from your inbox.
5. Press <kbd>Alt+D</kbd> when you want to clear the entire section in bulk.
