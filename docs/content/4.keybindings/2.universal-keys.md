Universal keybindings work regardless of which view (`prs`, `issues`, `notifications`, `agents`, or `repo`) is currently focused.

## Navigation Keys

| Key | Builtin Name | Action |
| :--- | :--- | :--- |
| <kbd>j</kbd> / <kbd>↓</kbd> | `down` | Move to next row |
| <kbd>k</kbd> / <kbd>↑</kbd> | `up` | Move to previous row |
| <kbd>g</kbd> / <kbd>Home</kbd> | `firstLine` | Jump to first row |
| <kbd>G</kbd> / <kbd>End</kbd> | `lastLine` | Jump to last row |
| <kbd>l</kbd> / <kbd>→</kbd> | `nextSection` | Switch to next tab |
| <kbd>h</kbd> / <kbd>←</kbd> | `prevSection` | Switch to previous tab |
| <kbd>J</kbd> / <kbd>PgDown</kbd> | `pageDown` | Scroll preview pane down |
| <kbd>K</kbd> / <kbd>PgUp</kbd> | `pageUp` | Scroll preview pane up |

## Application Keys

| Key | Builtin Name | Action |
| :--- | :--- | :--- |
| <kbd>?</kbd> | `help` | Toggle help overlay |
| <kbd>/</kbd> | `search` | Focus live search bar for active section |
| <kbd>p</kbd> | `togglePreview` | Toggle sidebar preview open / closed |
| <kbd>P</kbd> | `togglePreviewPosition` | Toggle preview position between Right and Bottom |
| <kbd>r</kbd> | `refresh` | Refresh current section |
| <kbd>R</kbd> | `refreshAll` | Refresh all sections in current view |
| <kbd>s</kbd> | `switchView` | Switch between PRs, Issues, Notifications, Agents |
| <kbd>y</kbd> | `copyNumber` | Copy PR / Issue number to clipboard |
| <kbd>Y</kbd> | `copyUrl` | Copy GitHub web URL to clipboard |
| <kbd>o</kbd> | `openGithub` | Open current item in default web browser |
| <kbd>U</kbd> | `updateCLI` | Check for updates and upgrade Forge to latest release |
| <kbd>Ctrl+L</kbd> | `redraw` | Clear terminal and redraw UI |
| <kbd>q</kbd> | `quit` | Exit Forge |
