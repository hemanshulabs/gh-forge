When focused on the **PRs** view, the following actions are available for the selected pull request:

## Keybindings Table

| Key | Builtin | Description |
| :--- | :--- | :--- |
| <kbd>d</kbd> | `diff` | Open full PR diff in terminal pager (e.g. `delta`, `bat`, `less`) |
| <kbd>v</kbd> | `approve` | Approve the pull request |
| <kbd>c</kbd> | `comment` | Open inline input box to leave a PR comment |
| <kbd>C</kbd> / <kbd>Space</kbd> | `checkout` | Checkout the PR branch in your local clone |
| <kbd>m</kbd> | `merge` | Merge the pull request |
| <kbd>w</kbd> | `watchChecks` | Watch CI/CD check suites run live in the terminal |
| <kbd>V</kbd> | `approveWorkflows`| Approve pending GitHub Actions workflows |
| <kbd>u</kbd> | `update` | Update PR branch from base branch |
| <kbd>W</kbd> | `ready` | Mark a draft PR as ready for review |
| <kbd>x</kbd> | `close` | Close the pull request (with prompt confirmation) |
| <kbd>X</kbd> | `reopen` | Reopen a closed pull request |
| <kbd>a</kbd> | `assign` | Assign reviewer or teammate |
| <kbd>A</kbd> | `unassign` | Unassign reviewer |
| <kbd>L</kbd> | `label` | Toggle issue / PR labels |
| <kbd>e</kbd> | `summaryViewMore`| Expand / collapse long description in sidebar |
| <kbd>[</kbd> / <kbd>]</kbd> | `prevSidebarTab` / `nextSidebarTab` | Switch between Overview and Activity tabs |

## Detailed Action Walkthroughs

### Viewing Diffs (`d`)
Pressing <kbd>d</kbd> shells out to git using your configured diff pager (configured via `$PAGER` or `defaults.pager`). You can browse file changes, additions, deletions, and syntax-highlighted chunks, then press <kbd>q</kbd> to return to Forge.

### Checking Out PRs (`C`)
If `repoPaths` is configured for the repository (or you are running Forge inside the repository), pressing <kbd>C</kbd> fetches the remote branch and checks it out directly into your local working tree.

### Submitting Reviews (`v`)
Pressing <kbd>v</kbd> focuses the sidebar input box for an approval review. Type your optional message and press <kbd>Enter</kbd> to submit directly to GitHub.
