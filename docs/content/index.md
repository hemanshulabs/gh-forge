#title
Everything You Need in One Terminal Window

#description
Forge eliminates context switching with five specialized views, instant diffs, and real-time interaction.

#features
  :::u-page-feature
  ---
  icon: i-lucide-git-pull-request
  to: /core-concepts/views
  ---
  #title
  Pull Request Management
  
  #description
  Browse PRs organized in customizable tabs, review code with full pager diffs, approve, merge, assign reviewers, inspect checks, and checkout branches locally with a single keypress.
  :::

  :::u-page-feature
  ---
  icon: i-lucide-circle-dot
  to: /core-concepts/views
  ---
  #title
  Issue Triage & Tracking
  
  #description
  Stay on top of issues across all your repositories. Filter by assigned, created, or mentioned. Read full comment threads, add labels, assign teammates, and close or reopen issues instantly.
  :::

  :::u-page-feature
  ---
  icon: i-lucide-bell
  to: /core-concepts/views
  ---
  #title
  Interactive Notifications
  
  #description
  Triage GitHub notifications with zero web overhead. Preview related PRs and Issues side-by-side in the sidebar, mark individual items as read, or mark entire sections done in one go.
  :::

  :::u-page-feature
  ---
  icon: i-lucide-git-branch
  to: /core-concepts/views
  ---
  #title
  Local Branch & Repo View
  
  #description
  Launch inside any git repository to browse local and remote branches, view recent commits, checkout branches, and safely delete merged branches with confirmation prompts.
  :::

  :::u-page-feature
  ---
  icon: i-lucide-arrow-up-circle
  to: /getting-started/updating
  ---
  #title
  One-Key In-App Updates
  
  #description
  Never fall behind. Whenever a new release is available, Forge displays a header badge. Press `U` to automatically check, download, and update the CLI extension via GitHub in seconds.
  :::

  :::u-page-feature
  ---
  icon: i-lucide-mouse
  to: /core-concepts/navigation
  ---
  #title
  Vim Keys & Mouse Scroll
  
  #description
  Full keyboard navigation (`j`/`k`, `h`/`l`, `g`/`G`, `/` search) paired with smooth, natural mouse wheel scrolling over both the main tables and sidebar preview panes.
  :::

  :::u-page-feature
  ---
  icon: i-lucide-palette
  to: /configuration/themes
  ---
  #title
  Themes & Full Customization
  
  #description
  Built on Lip Gloss and Bubble Tea with first-class support for Tokyo Night, Catppuccin, Gruvbox, Nord, Dracula, and custom hex themes, plus fully rebindable commands and YAML config.
  :::
